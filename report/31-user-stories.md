## 3.1. User Stories y Epics

A partir del análisis de las entrevistas y el modelo de negocio, se identifica que la plataforma actúa como un nexo logístico entre **Transportistas de Carga Terrestre**, quienes enfrentan pérdidas de rentabilidad por fletes de retorno vacíos, y **Pequeños y Medianos Emprendedores**, que buscan envíos más económicos, seguros y directos. 

Para estructurar el desarrollo de esta solución, se han definido grandes iniciativas (*Epics*) que abarcan desde el pilar fundamental de la gestión de identidad y atracción de usuarios (mediante el Landing Page y la API RESTful), hasta el corazón del negocio (publicación de carga y monitoreo).

A continuación se presenta el desglose de User Stories agrupadas por sus respectivas Epics. Se ha priorizado el flujo básico de registro y autenticación (Login/Register), así como requerimientos técnicos para desarrolladores y de marketing para visitantes, utilizando la estructura de criterios de aceptación *Given-When-Then* en tercera persona y sin mención a componentes específicos de interfaz.
